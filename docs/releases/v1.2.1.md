# v1.2.1 Patch Update

This patch update standardizes VS Code PDF preview behavior across the template
branches and relaxes Python-backed hook expectations where they do not match
the coursework profile.

## Changed

- Added the LaTeX Workshop PDF viewer association for `*.pdf` files across all
  template branches.
- Recommended LaTeX Workshop anywhere that PDF association is configured.
- Removed the Python-powered hook layer from the ENG1005 LaTeX and MARIE
  template branches.
- Made FIT1045 text-policy hooks inactive by default; contributors can opt in
  with `MONASH_TEXT_POLICY_ENFORCE=1`.
- Updated branch documentation so setup instructions match each profile.

## Validation

- Confirmed each branch has the PDF viewer association and extension
  recommendation.
- Confirmed ENG1005 and MARIE no longer track `.githooks`, hook helper tools,
  or Python hook version markers.
- Confirmed FIT1045 pre-commit and pre-push hooks exit successfully by default
  without requiring Python.
